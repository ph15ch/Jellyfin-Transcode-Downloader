How many queued downloads run at the same time (1–5). Every download is a transcode running on this server, so this is equally the number of simultaneous transcodes the plugin will start.
The default of 1 keeps the queue strictly sequential. Raise it only if this server has the CPU or GPU headroom for several transcodes at once: each download also holds its whole file in the browser's memory until it finishes, and browsers ask for permission the first time a site saves several files at once.
This limit applies to the plugin's own download queue. Jellyfin's server-wide transcoding settings (Dashboard → Playback) still apply on top of it.
